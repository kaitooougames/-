# 怪盗ゲーム Webオンライン版

## Web版を作る

1. Unityの再生を停止する。
2. `怪盗ゲーム > Web・オンライン > Web版を作る`を選ぶ。
3. 完成すると`Builds/KaitouOnlineWebGL`がFinderで開く。

メニューが表示されない場合は、Unity HubのUnity 6000.0.26f1へ`WebGL Build Support`を追加してUnityを再起動する。

## 公開する

`Builds/KaitouOnlineWebGL`フォルダの中身を、Netlify Dropなどの静的Webホスティングへアップロードする。`index.html`をFinderから直接開く方法では動作しない。

## 対戦する

1. 2人が公開URLを開く。
2. 片方が`オンライン対戦 > 部屋を作る`を押す。
3. 表示された参加コードを相手へ送る。
4. 相手がコードを入力して`参加コードで入る`を押す。
5. 接続人数が揃ったら、ホストが`対戦開始`を押す。

WebGLではRelay接続に`wss`を使用する。Unity Services側でAuthenticationとRelayが有効になっている必要がある。

## 確認項目

- 部屋作成と参加コードによる入室
- 行動カードの伏せ移動、カメラ移動、一斉開示
- 宝の展示・怪盗・檻・逮捕・ペナルティ
- 特殊行動カード
- 脱落者の宝の全展示と勝利判定
- ゲーム終了後の再戦

ブラウザでは最初に画面をクリックするまで音が鳴らない場合がある。スマートフォンでは横画面を推奨する。
